# 藤橋JVC 会計管理アプリ

藤橋JVC（小学生バレーボールチーム）の会計を、スマホとパソコンで管理するための Web アプリです。
三浦塾のアプリとは関係のない、独立したアプリです。リポジトリ `miurajyuku` の中の `fujihashi-jvc` フォルダに入っています。

## 第1版でできること

| 画面 | 内容 |
|---|---|
| ホーム | 現金残高、今月の土日祝の会計ページ、月謝の未回収、遠征交通費の未集金、運転手への未払い、当番準備金の未渡し、未精算の経費、最近の入出金 |
| 活動日（カレンダー） | 土日祝が色付きで表示されます（祝日・振替休日は自動計算）。日付を押すと、その日の会計ページを開くか作成します |
| 月間予定表の取り込み | 画像や PDF（AI）またはテキスト（端末内・無料）から、日付・活動名・会場・当番を読み取ります。土日祝の活動だけを初期選択し、1日1ページにまとめます。読み取れない項目は「要確認」で黄色表示。再度取り込んだときは**差分だけ**を一覧で確認して反映し、集金・支払いの記録は消しません。予定表から外れた当番は「取消」扱いにして、記録は残します |
| 日別会計ページ | 活動・会場の編集、当番と準備金、配車と交通費の集金、運転手への支払い、関連する経費、準備金の差額精算、メモ、変更履歴 |
| 配車表の取り込み | LINE の文章（端末内）またはスクリーンショット（AI）を読み取り、運転手・選手・帯同保護者・その他（要確認）に分類します。名簿と照合し、重複した人がいると登録できません。指導者（設定した名前）が乗っている車を基準車両として自動で選びます |
| 交通費 | 高速あり：選手1,000円・帯同保護者1,000円・運転手0円。高速なし：0円。高速利用を「要確認」にしている間は金額が未確定です。兄弟は1人ずつ数え、保護者が運転手でも子どもは集金対象です。1人ずつ金額を変更でき（例外）、「集金」ボタンで集金済みと集金日を記録します |
| 運転手への支払い | 基準車両の走行距離・ガソリン代（手入力）・往復高速代を確定すると、全運転手に同額を表示します。人ごとに金額を変更でき、支払日と支払済みも記録します |
| 当番準備金 | 当番ごとに金額を自由に編集できます。「渡した」で渡した日付と金額を記録します |
| 経費・レシート | 撮影または添付（暗号化して端末内に保存）、AI で金額などを読み取り、購入日・購入者・品目・分類（飲み物・弁当・備品・その他）・金額を記録します。支払い元は「事前に渡したお金」か「立て替え」を選べます。購入日と違う活動日にも関連付けでき、備品は関連付けなしでも登録できます。立て替えは全額を精算し、準備金は「渡した額 − 購入額」の差額を精算します（あとからレシートを追加した場合は残りの差額だけ再精算） |
| 月謝（家庭単位） | 名簿（家庭・選手・月謝額）の管理と、貼り付けによる一括登録。月謝袋の作成（配布日を記録）、回収期限（31日が無い月にも対応）、一部入金、未回収額 |
| 出納帳 | すべての入出金を自動で記帳し、二重計上を防止します。修正・取り消しは理由つきで履歴に残ります。月別・年度別の収支と科目別の内訳を表示します |
| CSV | 出納帳・月謝・交通費・経費（Excel で開けます） |
| バックアップ | レシート画像を含めて暗号化バックアップを保存・復元できます。年度締めにも対応しています |

## 起動方法

### パソコンで試す（開発者向け）
```bash
cd fujihashi-jvc
npm install
npm run dev        # http://localhost:5173 を開く
npm test           # 計算ルールのテスト
```

### 公開してスマホで使う（無料・Netlify）
1. https://app.netlify.com に GitHub でログインし、「Add new project」→「Import an existing project」→ `miurajyuku` を選びます。
2. **Base directory** に `fujihashi-jvc`、**Branch** に `claude/fujihashi-jvc-accounting-app-ab6q53` を設定して Deploy します。
3. 表示された `https://〇〇.netlify.app` をスマホで開き、「ホーム画面に追加」します。

AI 読み取り（画像）を使う場合だけ、Netlify の環境変数に次を設定します。設定しなくても、テキスト読み取りと手入力ですべての機能が使えます。

| 変数 | 内容 |
|---|---|
| `APP_ACCESS_TOKEN` | 16文字以上のランダムな文字列。アプリの「設定 → サーバー接続トークン」にも同じ値を入れます |
| `ANTHROPIC_API_KEY` | https://console.anthropic.com で発行 |
| `CLAUDE_MODEL` | 任意。既定は `claude-opus-5-5` |

AI 読み取りの費用は、画像1枚あたり**約5〜15円**の目安です（月30枚で数百円程度）。Anthropic の前払いクレジット制で、上限を設定できます。

## 動作確認の手順（サンプルデータ）

1. 初回画面でパスコードを決め、「サンプルデータで動作確認する」にチェックを入れて開始します。
2. **ホーム**に、今月の会計ページ、月謝の未回収、未集金、未払いが表示されることを確認します。
3. **活動日** → 色付きの日付を開きます。
   - 「集金」を押す → 出納帳に入金が記録され、ホームの未集金が減ります（直後なら「取り消す」で戻せます）。
   - 高速利用を「なし」にする → 集金額が0円になります。「要確認」にする → 金額が未確定になります。
   - 運転手欄にガソリン代と高速代を入れて「確定」→ 全運転手に同額が表示され、「支払う」で記録されます。
4. **配車表を取り込む** → 「サンプル文章を入れる」→「読み取る」。重複（ゆい）の警告が出て、削除すると登録できることを確認します。
5. **＋経費** → 画像を添付し、金額を入力して保存 → 会計ページの「準備金の差額精算」に差額が表示されます。
6. **活動日 → 月間予定表を取り込む → テキスト** → サンプル文章の当番名や会場を書き換えて読み取り →「変更点を確認」で差分だけが表示されることを確認します。
7. **月謝** → 翌月に移動 →「〇月分を作成」→ 金額を変えて「受取」（一部入金）→ 未回収が残ることを確認します。
8. **出納帳** で記録・修正履歴・CSV を、**設定** でバックアップの保存を確認します。

## 要確認事項（勝手に決めず、設定で変更できるようにしたもの）

- **月謝の回収期限**：「対象月の末日」か「配布した月の末日」か（初期値は対象月の末日。設定で切り替えられます）
- **月謝の金額・当番準備金の初期値**：未設定（要確認）。家庭ごと・当番ごとに入力します
- **ガソリン代の距離別計算式**：未確認のため手入力です
- **基準車両の指導者名**：初期値は「先野」。設定で変更できます
- **名簿にない同乗者**（兄弟の付き添いなど）の交通費：「その他（要確認）」に分類し、金額は手入力です
- **祝日**：法律どおり自動計算しています。臨時の休日や学校行事の日は、カレンダーから手動でページを作成してください

## 未実装・制限事項

- **保護者がそれぞれ自分のスマホから経費を登録する機能**：第1版は会計係の端末で、購入者名を入れて代理で登録する方式です。保護者ごとのログインやデータ共有には、サーバー（データベース・認証）が必要です（Supabase や Firebase の無料枠で可能。次の段階でご相談）。
- **複数端末での共有・自動同期**：データはその端末のブラウザ内に保存されます。機種変更や引き継ぎにはバックアップの保存と復元を使います。
- 画像の読み取りには AI（有料 API・サーバー設定）が必要です。無料の読み取りはテキストのみです。
- 通知（リマインド）機能は第1版には入れていません（ホーム画面の一覧で確認できます）。
- 旧版（第0版）の遠征・当番データは引き継ぎません（出納帳の取引のみ引き継ぎます）。

## 個人情報の保護

- パスコードでロックし、データは PBKDF2 と AES-256-GCM で暗号化して端末内に保存します。レシート画像も同じ鍵で暗号化し、ロック解除中だけ表示できます。
- 一定時間操作しないと自動でロックされます。パスコードを続けて間違えると、しばらく入力できなくなります。
- 外部に送るのは「AIで読み取る」を押したときの画像・文章（と照合用の選手名）だけです。Anthropic の API では、送ったデータは標準設定ではモデルの学習に使われません。
- CSV は数式として実行されないよう対策しています。

## 構成

- `src/lib/day.ts` 日別会計（交通費・運転手・準備金・配車の分類・予定表の差分）
- `src/lib/expense.ts` 経費と差額精算 ／ `fees.ts` 月謝 ／ `ledger.ts` 出納帳 ／ `holidays.ts` 祝日
- `src/lib/vault.ts` 暗号化保存（データ・画像）
- `netlify/functions/ai-parse.mts` AI 読み取り（予定表・配車表・レシート。JSON 形式で返し、必ず確認画面を経由）
- `tests/` 計算ルールのテスト
