# 藤橋JVC 会計係アプリ

ジュニアバレーボールチーム「藤橋JVC」の会計係が、スマートフォンで現金管理をするための Web アプリ（PWA）です。
利用者は会計係だけです。保護者がアプリに登録したり操作したりする必要はありません。

## できること

| 画面 | 内容 |
|---|---|
| ホーム | 現金残高、今日までに集める／渡すお金、部費の未払い、遠征費の未回収、ガソリン代・高速代の未精算、直近の当番への支払い予定、期限超過アラート |
| 部費 | 部員ごとの月額を設定。毎月の集金予定を自動作成し、ワンタップで「受取」を記録（直後なら取り消し可）。未入金者を自動で抽出し、LINE 用の確認メッセージを作成 |
| 遠征 | LINE の車割り文章を貼り付けて解析。日付、車、運転手、子ども・大人・兄弟姉妹を抽出。全員に集金対象チェックボックスを付け、運転手を免除するかも切り替え可。重複した名前や名簿にない名前は確認画面で警告。集金対象の選択と入金確認は別々に管理 |
| 遠征の精算 | 遠征ごとにルール（交通費の事前集金、ガソリン・高速・駐車場・その他の精算）を設定。ガソリン代は Google Maps のルート距離から A（km×円/km）または B（km÷燃費×円/L）で見積もり、会計係が確定。確定時の計算条件は保存されるので、あとで設定を変えても変わりません。高速代は概算を表示し、申告額を手入力で確定 |
| 当番 | 予定表（テキスト／画像／PDF）を取り込み、確認してから登録。担当者の変更、取消、中止、複数人の当番、個別の金額と支払いに対応。LINE の変更連絡から変更候補を作成。支払い済みの当番は自動で削除せず、「返金を受け取った／支払い済みのまま保持」を選んでもらいます |
| リマインド | 部費、遠征前の集金、当番への支払い（前日・当日）、遠征後の精算、期限超過。通知時刻は変更可能。端末通知と、カレンダー用の .ics 書き出しに対応 |
| 出納帳 | すべての入出金を自動で記帳します（日付、相手、金額、入出金の区分、内容、関連する遠征・当番、記録者）。二重計上は防止。修正・取り消しは理由つきで履歴に残ります。月別・年度別の集計と CSV 出力（Excel 対応） |
| 設定 | 各種金額、ガソリン単価・燃費、リマインド、LINE 文面の雛形、自動ロック、パスコード変更、暗号化バックアップと復元（引き継ぎ用）、年度締め |

## セキュリティと個人情報

- 初回にパスコード（6文字以上）を設定します。データは PBKDF2（31万回）で作った鍵を使い、AES-256-GCM で暗号化して、端末内の IndexedDB に保存します。パスコードを忘れると復元できません。
- 一定時間操作がないと自動でロックされます。パスコードを5回続けて間違えると、しばらく入力できなくなります。
- データはサーバーに置きません。外部に送るのは次の場合だけです。
  - 「🤖 AIで読み取る」を押したとき: 貼り付けた文章または画像と、照合用の部員名を Anthropic（Claude API）に送ります。API で送ったデータは、標準設定ではモデルの学習に使われません。
  - 「ルートを検索」を押したとき: 出発地・経由地・目的地を Google に送ります。
- 「端末内で読み取る」を選べば、文章をどこにも送りません。
- LINE の確認メッセージに個人名は入れていません。CSV は数式として実行されないよう対策しています。.ics には件数と金額だけを入れ、名前は入れていません。

## 使い方（ローカルで確認）

```bash
cd fujihashi-jvc
npm install
npm run dev      # http://localhost:5173
npm test         # ロジックのテスト
npm run build
```

初回の画面で「サンプルデータで動作確認する」にチェックを入れると、架空の部員20名と、遠征・当番・入出金のサンプルが入ります。サンプルは設定画面から置き換え・消去できます。

## 公開（Netlify）

1. Netlify で新しいサイトを作り、このリポジトリを選びます。**Base directory** に `fujihashi-jvc` を指定します（ビルド設定は `netlify.toml` から自動で読み込まれます）。
2. Site settings → Environment variables に次を設定します。

| 変数 | 必須 | 内容 |
|---|---|---|
| `APP_ACCESS_TOKEN` | AI・ルート検索を使う場合 | 16文字以上のランダムな文字列。アプリの「設定 → サーバー接続トークン」にも同じ値を入れます。これを知らない人はサーバー関数を呼べません |
| `ANTHROPIC_API_KEY` | AI読み取りを使う場合 | https://console.anthropic.com で発行 |
| `GOOGLE_MAPS_API_KEY` | ルート検索を使う場合 | Google Cloud で **Routes API** を有効にして発行。API の制限で Routes API だけを許可してください |
| `CLAUDE_MODEL` | 任意 | 既定は `claude-opus-5-5` |

3. スマホでサイトを開き、「ホーム画面に追加」すると、アプリとして全画面で使えます（iPhone の通知はホーム画面に追加した場合のみ使えます）。

AI もルート検索も使わない場合、環境変数は不要です。車割り・予定表のテキストは端末内で解析し、距離は手入力すれば、すべて無料で使えます。

## 外部サービスの料金（目安）

| サービス | 用途 | 想定費用 |
|---|---|---|
| Netlify | ホスティング・サーバー関数 | 無料プランの範囲内 |
| Claude API（Anthropic） | 車割り・予定表・変更連絡の AI 読み取り | Claude Opus 5.5 は入力 $4／出力 $20（100万トークンあたり）。1回の読み取りは入力・出力（思考を含む）合わせて数千トークンで、**1回あたり約5〜15円**（画像・PDFはやや高め）。月20回で100〜300円程度です。`CLAUDE_MODEL=claude-haiku-5-5` にすると、精度は下がる可能性がありますが大幅に安くなります。前払いのクレジット制で、Console で上限を設定できます |
| Google Maps Platform Routes API | 走行距離と高速料金の概算 | 有料の API ですが、毎月の無料枠があります。高速料金の取得を含むリクエストは上位の SKU（Enterprise、無料枠は月1,000回程度、超過時は1,000回あたり約$15）で課金される可能性があります。月数十回なら**実質0円**です。Google Cloud の請求先アカウント（カード）の登録が必要なため、予算アラートの設定をおすすめします |
| 端末通知・カレンダー通知 | リマインド | 0円（外部のプッシュ通知サービスは使っていません） |

料金は 2026年11月時点の公開情報にもとづく目安です。最新の料金は各サービスの料金ページで確認してください。

### 通知について

- アプリを開いたときと開いている間は、通知時刻を過ぎると端末通知を出します（通知の許可が必要です）。
- アプリを閉じているときも通知を受けたい場合は、リマインド画面から **.ics をカレンダーに取り込んで**ください。カレンダーのアラームで通知されます。
- アプリを閉じた状態のプッシュ通知（Web Push）には、常に動いている通知サーバーが必要です。費用と運用の手間がかかるため、初期版では見送っています。通知が使えない環境でも、アプリ内の「リマインド」一覧で確認できます。

## 年度の引き継ぎ

1. 設定 →「年度締め」で、その年度の出納帳 CSV と暗号化バックアップを保存し、その年度の取引をロックします。残高は翌年度に繰り越されます。
2. 次の会計係には、バックアップファイルとパスコードを**別々の方法で**渡してください。
3. 新しい会計係は、自分の端末で初期設定をしてから「バックアップから復元」を使います。

## 構成

- `src/lib/` 業務ロジック（出納帳、部費、遠征、当番、ガソリン計算、LINE解析、リマインド、暗号化）
- `src/pages/` 画面
- `netlify/functions/ai-parse.mts` Claude API による構造化抽出（JSON スキーマ指定。結果は必ず確認画面を経由）
- `netlify/functions/route.mts` Google Routes API
- `tests/` Vitest によるロジックのテスト
