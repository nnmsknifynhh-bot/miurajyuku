# 三浦塾 バーチャル教室（2D）

ブラウザで動く、学習塾向けの 2D 仮想空間です。生徒や先生がアバターで入室し、近くの人と通話したり、面談室で画面共有したりできます。

## できること

| 機能 | 内容 |
| --- | --- |
| 入室・着席 | 名前と「生徒 / 先生」を選んで入室。「空いている席に座る」にチェックすると、生徒は教室の空席へ、先生は教卓へ自動で歩いて着席します |
| 移動 | WASD / 矢印キー、または床をクリック（自動で経路を歩きます）。椅子をクリックするとそこへ行って座ります。Space で座る/立つ |
| 近接通話 | 近く（約3.5マス）に来た人と自動で音声がつながります。距離が近いほど大きく聞こえます |
| 面談室A / B 🔒 | 部屋にいる全員と距離に関係なく通話。外には聞こえません。画面共有はここで使うのが基本です |
| 自習室 🤫 | 通話がオフになる静かな部屋です |
| 画面共有・カメラ | ツールバーから ON/OFF。つながっている相手の上部に表示され、画面共有はクリックで拡大表示 |
| チャット | 全員チャット＋アバターの吹き出し。先生は「全員にアナウンス」で画面上部にバナー表示 |
| 先生専用 | 「部屋全体に話す」（同じ部屋の全員に声が届く）、生徒を「呼ぶ」（生徒に通知が届き、ボタンで先生のそばへ移動）、動作確認用の「デモ生徒」入室 |

## 起動方法

```bash
cd virtual-classroom
npm install
npm start
# → http://localhost:3000
```

環境変数（任意）:

| 変数 | 説明 |
| --- | --- |
| `PORT` | ポート番号（既定 3000） |
| `TEACHER_PASSCODE` | 設定すると、先生として入室するときにパスコードが必要になります |
| `TURN_URL` / `TURN_USERNAME` / `TURN_CREDENTIAL` | TURN サーバー（学校・企業ネットワークなどで通話がつながらない場合に設定） |

## 公開（本番運用）するとき

- マイク・カメラ・画面共有は **HTTPS** でないと使えません（localhost は例外）。
- Netlify などの静的ホスティングでは動きません。Node.js が常時動くサービス（Render、Railway、Fly.io、VPS など）にデプロイしてください。
- 音声・映像は参加者同士の P2P（WebRTC メッシュ）です。1つの通話グループが 6〜8 人程度までを想定しています。家庭のネットワークによってはつながらないことがあるため、本番では TURN サーバーの用意をおすすめします。
- 入室時の名前は自己申告です。生徒ごとのログインが必要になったら、既存の三浦塾アプリのアカウントと連携させるのが次のステップです。

## 構成

```
virtual-classroom/
  server.js            位置・状態の同期（Socket.IO）、WebRTC シグナリング中継、デモ生徒
  public/
    index.html, style.css
    shared/map.js      マップ・部屋・席の定義（サーバーと共通）
    js/main.js         描画・移動・近接判定・UI
    js/rtc.js          WebRTC 接続管理（マイク/カメラ/画面共有）
```

マップのレイアウトは `public/shared/map.js` で変更できます（記号で机・椅子・壁などを配置）。
