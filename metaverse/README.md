# 三浦塾 2Dメタバース オンライン教室

小中学生がスマートフォンから参加できる、見下ろし型2Dの塾空間です。
技術構成・費用・スマホの制約・画面とDBの設計・実装計画は [docs/DESIGN.md](docs/DESIGN.md) にまとめています。

## 起動方法

Node.js 22.13 以上が必要です（データベースは Node.js 標準の SQLite を使うので、追加インストールは不要です）。

```bash
cd metaverse
npm install
npm start
# → http://localhost:3000
```

データは `metaverse/data/app.db` に保存されます（`DB_PATH` で変更可）。

| 環境変数 | 説明 |
| --- | --- |
| `PORT` | ポート番号（既定 3000） |
| `DB_PATH` | データベースファイルの場所 |
| `NODE_ENV=production` | Cookie を HTTPS 専用にする（本番では必ず設定） |
| `TRUST_PROXY=1` | Render などのプロキシの後ろで動かすとき |
| `SESSION_DAYS` | ログインの有効日数（既定 7） |

## 第1段階の確認方法

### 自動テスト
```bash
npm test
```
サーバー側の権限チェックを13項目確認します（未ログイン拒否、生徒・先生の管理API拒否、生徒に通話権限を付けられないこと、先生は担当教室だけ入れること、強制ログアウト・無効化、ログイン試行の制限、他サイトからのリクエスト拒否、パスワードのハッシュ化 など）。

### 手で確認する手順
1. `npm start` → ブラウザで http://localhost:3000 を開く → 「はじめての設定」でオーナーを作成。
2. 管理画面の「＋ユーザーを追加」で、先生（担当：教室2）と生徒を1人ずつ作る。作成後に表示されるログイン情報をメモ。
3. 「教室の設定」で自習室の定員を変える → 2D空間の自習室で「定員○人」の表示が変わる。
4. 別のブラウザ（またはシークレットウィンドウ）で生徒としてログイン → 「へやをえらぶ」→ 教室を選ぶと、席まで歩いて座る。
5. 先生としてログイン → 教室1・3が🔒で暗く表示され、入ろうとすると「担当の教室ではありません」と出る。教室2を選ぶと教壇へ移動する。
6. オーナーの管理画面で生徒を「強制ログアウト」→ 生徒の画面は1分以内にログイン画面へ戻る。

### スマートフォンで確認する
同じ Wi-Fi のスマホから `http://（PCのIPアドレス）:3000` で開けます。タップ移動・スティック・2本指ズームを試せます。
※ PWA のインストールと、第3段階以降のマイク・画面共有は HTTPS が必要です。スマホで本格的に試すときは HTTPS で公開した環境を使ってください。

## セキュリティ（第1段階で実装済みのもの）
- パスワードは scrypt でハッシュ化して保存。ログイン試行は同じIDで5回失敗すると15分ロック。
- ログイン状態はサーバー側セッション（HttpOnly・SameSite Cookie）。無効化・パスワード再発行・強制ログアウトで即座に無効化。
- 管理APIはすべてサーバー側で役割・権限を確認。生徒には通話・画面共有・管理の権限を付けられない（APIで送っても保存されない）。
- 他サイトからの書き込みリクエストを拒否、Content-Security-Policy などのセキュリティヘッダーを設定。
- 個人情報は表示名・ログインID・役割・色のみ保存。
- 本番は HTTPS（`NODE_ENV=production`）で運用してください。

```
  server/
    server.js        API（ログイン・管理）、セキュリティヘッダー

    db.js            テーブル定義（SQLite）
  public/
    index.html       ログイン／初期設定
    app.html         2D空間
    admin.html       管理画面
    shared/map.js    マップ（教室・席・自習室）の定義。サーバーと共通

    js/app.js        移動・タップ・スティック・部屋えらび
    js/admin.js      管理画面
    sw.js, manifest.webmanifest   PWA
  test/api.test.js   API テスト
  docs/DESIGN.md     設計書
```
