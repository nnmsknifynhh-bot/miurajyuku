### がんばりの仕組み（自習を続けたくなる工夫）
- **自習時間の記録**：自習室で、アプリを見ている（離席していない）生徒の時間を1分ずつ自動で数えます。数え方はオーナーが管理画面「🏆 がんばり」で決めます。
  - 数える時間帯
  - 1日の上限
  - 席に座っているときだけ数えるか
  - 見守り写真がオンのとき、カメラがオンのときだけ数えるか
  - 生徒ごと・日ごとに時間を修正することもできます（修正した値が優先されます）
- **学年の木（3本）**：自習室の真ん中にあります。今学期の「学年の生徒1人あたりの**平均**自習時間」で育ちます（芽 → 若葉 → 若木 → 大きな木 → 花 → 実り）。木の名前・ふくめる学年・段階の時間は変えられます。木をタップすると詳しく見られます。
- **目標の短冊**：生徒がメニューの「🎯 今学期の目標」で目標を書くと、先生が「確認OK」にしたあとで学年の木に短冊として飾られます。「達成」にすると⭐になります。目標の確認は、オーナーと「生徒への個別対応」の権限がある先生ができます。
- **ポイントと着せかえ**：今年度の自習時間でポイントがたまります（初期設定は10分で1ポイント）。メニューの「🎁 ポイントと着せかえ」で交換できます。
  - 種類：帽子・洋服・眼鏡・杖や剣・ペット・着ぐるみの6種類です。値段は20〜300ポイントで、季節限定のアイテムもあります。
  - 着ぐるみを着ているあいだは、帽子と洋服は表示されません。
  - **ポイントとアイテムは新年度になっても引きつぎます（0にもどりません）。**
- **着せかえ期間**：管理画面「🏆 がんばり」→「👕 着せかえ期間」で、「いつでも」か「期間を決める」（例：冬休み 12/27〜1/6、複数可）を選べます。
  - 期間の外は、着せかえを**買う・着ることができず、誰にも見えません**。持っているアイテムとポイントは消えません。
  - 保護者レポートのアバターも、期間の外は着せかえなしで表示されます。
- **連続自習🔥**：1日の最低時間（初期設定**90分**）を続けた日数を、名前の横に表示します。
- **季節の飾り**：その時期になると、ロビー・ろうか・自習室に飾りが出ます。画面に舞う演出はありません。木の葉の色は季節で変わります。管理画面で1つずつオン・オフできます。
  - 1年中なにかの飾りが出ます（23こ）：お正月（1/1〜1/15）、冬・雪、節分、バレンタイン、ひな祭り（2/15〜3/3）、ホワイトデー、卒業式、入学式、お花見、こどもの日、母の日、新緑、あじさい・梅雨、七夕、夏・ひまわり、夏祭り・花火、秋の始まり、お月見、ハロウィン、紅葉・秋、秋の収穫祭、クリスマス、お正月準備（12/26〜12/31）
- **保護者レポート**：オーナーが学期ごとに作ります。内容は、総自習時間・自習した日数・現在のアバター・目標・学年の木・先生からのひとことです。
  - 「全員分のリンクを作る」でリンクの一覧を作り、LINE などで送れます。
  - レポートのページの「画像で保存」で、画像として保存することもできます。
  - リンクを知っている人だけが、その子の1人分を見られます（ログイン不要・期限は120日）。
- **新年度**：管理画面の「新年度にする」で切り替えます。学年を1つ上げることもできます。3学期のレポートは、新年度にする前に作ってください。

### 勉強時間（全部）とポイントになる時間
- 自習室で条件（すわる・離席しない など）を満たしていれば、ポイントの時間帯の外・数えない曜日・1日の上限のあとも「勉強時間（全部）」として数える。
- 全部の時間を使うもの：名札の「今日○分」、🔥（最低時間）、がんばりサンタの日数、高校生の週の回数、保護者の「わが子」画面。
- ポイントになる時間を使うもの：ポイント、学年の木、ランキング、朝活チャレンジ。
- ショップの上には「今日 2時間10分（ポイントになる時間 1時間30分）」のように両方が出る。

### 授業の曜日（🔥がとぎれない）
- 管理画面の生徒の編集で「授業の曜日」をチェック（塾の教室での授業）。その曜日は自習しなくても🔥がとぎれない。自習して最低時間をこえれば1日に数える。

### 👀 オーナーの「見わたす」
- オーナーの下のボタン「👀 見わたす」で塾全体を見わたせる（指・ドラッグでずらす、＋−・2本指・ホイールで大きさ）。「もどる」・歩く・キー操作でふつうの画面にもどる。

### 🔋 省電力画面・電池のお知らせ
- 自習室で席にすわって1分さわらないと、黒い省電力画面（時刻・今日の自習時間・🔥・電池）に切りかわる。地図をかかないので電池の減りが少ない。自習時間はそのまま数える。
- タップ・先生が近くに来た・個別通話・画面（ダイアログ）が開いたときは元にもどる。
- 電池が20%を切って充電していないと「充電しながら勉強しよう」と出る（電池の残りを読めるブラウザだけ。iPhone は不可）。

### 入室前の漢字テスト（漢検の読み・4択）
- 生徒がオンライン教室に入るとき、学年に合った級から読みの問題を1問出します。初期設定は、中1：5〜4級、中2：4〜3級、中3：3〜準2級です（ほかの学年は出題しません）。
- 正解でも不正解でも、**正しい読みを見てから入室**できます。通信が一瞬切れて入り直すときは出しません。
- 答えないと入室できません。サーバー側でも確認しています。
- 管理画面「✏️ 漢字テスト」（オーナー）でできること：
  - オン・オフ、学年ごとの級の設定
  - 生徒ごとの成績（最近30日の正答率）
  - 問題の追加・修正・お休み・削除
- **まとめて追加**：「✏️ 漢字テスト」→「📋 まとめて追加」で、表計算ソフトから貼り付けて一度に登録できます（最大1000問）。
  - 表は「級・漢字・正しい読み・まちがい1・まちがい2・まちがい3」の6列です。ひな形と今の問題は、CSV でダウンロードできます。
  - まちがいの読みが空欄なら自動で作ります（🤖の印。別の正しい読みになっていないか確認してください）。
  - 同じ級・同じ漢字の問題はとばし、まちがいがある行は理由を表示します。
- 最初に入っている問題（各級15〜18問）は**サンプル**です。級の分け方は目安なので、先生が確認して、必要なら直したり追加したりしてください。

### 生徒の入室の通知（先生・オーナー）
- 生徒がアプリに入ると、オーナーと先生に知らせます（10分以内の入り直しは知らせません）。
  - **アプリを開いているとき**：画面に「🔔 はなさんが入室しました（時刻）」と表示し、チャイムが鳴ります。
  - **アプリを閉じているとき**：スマホやパソコンに**プッシュ通知**が届きます（無料）。
- 設定は右上の名前のボタン → **「🔔 入室の通知」**。
  - 「入室の通知を受け取る」のオン・オフ（最初はオン）
  - **「この端末で受け取る」** を押して通知を「許可」すると、その端末に、アプリを閉じていても届くようになります。**「テスト通知を送る」** で確かめられます。
  - **iPhone・iPad** は、Safari の共有ボタン →「ホーム画面に追加」をして、**ホーム画面のアイコンから開いたとき**に設定できます（Apple の仕組みのため）。
- プッシュ通知の鍵は初回起動時に自動で作られ、データと一緒に保存されます。追加の登録・設定は不要です。

### スピーキング・ライティング教室（教室1を改装）
- 中学生も高校生も入れる「テストの教室」です。自習時間・見守り写真・着席のうながしなどは自習室と同じルールです（数え方は学年に合わせて中学生用・高校生用）。
- 教壇の前に **テスト用のブースが2つ**（ブース1・ブース2）。うしろの15席は順番を待つ間の自習席です。ブースには、先生に呼ばれた生徒しかすわれません。
- **生徒**：下の「🎤 テストに並ぶ」で順番待ちに並びます（ボタンに「2番目」のように出ます）。呼ばれると自動でブースへ移動します。
- **先生・オーナー**（生徒への個別対応の権限あり）：この教室に入ると右上に「🎤 テストの受付」が出ます。空いているブースの「▶ 次の人を呼ぶ」で1番目の生徒を呼び、スピーキングは「🎧 通話」で話します。終わったら「✅ 終了」でブースをあけます（生徒は近くの席にもどります）。
- 生徒が並ぶと、教室の外にいる先生にもお知らせが出ます。部屋を出た生徒・2分以上通信が切れた生徒は、順番待ちからぬけます。
- 授業（声・画面共有）は教室2で行います。

### 高校生自習室（教室3を改装・カフェ風）
- 高校生（高1〜高3）は「☕ 高校生自習室」で自習します（中学生などは今までの自習室）。自習時間・見守り写真・着席のうながし・今日の自習時間の表示などは自習室と同じです。
- **数え方（時間帯・上限・曜日）は高校生だけ別に**決められます（管理画面「🏆 がんばり」→「⏱ 自習時間の数え方」→「☕ 高校生自習室」）。
- **週のノルマ**：3時間（変更可）以上自習した日を「1回」と数え、週2回（変更可）で達成。画面の左上に「📅 今週 ●○ 1/2回・今日 1:40/3:00」と出ます。達成した週はボーナスポイント。高校生の🔥は「達成した週」が続いた数です。
- **今日やること**：高校生自習室に入ると、今日やることを3つ書いてから始めます。頭の上に吹き出しで出ます。
- **来る曜日**：「ユーザー」で高校生を編集し、来る曜日と時刻を決めると、その時刻を過ぎても来ていないとき（15分後・変更可）に先生へ通知が届きます。
- **称号**：自習時間の合計で、名前の前に【がんばり屋】【努力家】【鉄人】【勉強の達人】【受験の覇者】【伝説の受験生】がつきます。
- **高校生の木**（4本目）と短冊（目標）もあります。

### 保護者の参加（ロビーだけ・1日1回10分）
- 登録：管理画面「ユーザー」→ 生徒の「👪 保護者」→「招待コードを作る」。保護者はログイン画面の「保護者の方で、はじめて登録する方はこちら」からコードを入れて自分のID・パスワードを決める（コードは1回だけ）。きょうだいは「わが子」画面からコードを追加。
- 入れるのはロビーだけ。入るとソファ（3つ・各2席）をえらぶ画面が出て、すわると塾全体を見わたせる（指でずらす・＋−で大きさを変える）。
- 10分で自動退室、その日はもう入れない。毎日来たら🔥で連続日数を数える（滞在時間は関係なし）。
- 毎日5問（4択・中学レベル）。教科は日替わりで 漢字→英単語→数学→理科→社会。漢字は漢字テストの4級〜準2級から、ほかは管理画面「✏️ 漢字テスト」の下の「👪 保護者の今日の5問」で追加・削除。1問正解で1ポイント。ポイントは生徒と同じく着せかえ期間にショップで使える。
- 名前の表示：生徒からは「🏠 保護者」とだけ見える。保護者からは自分の子だけ名前（💗）、ほかの子は「生徒」（自習時間と🔥は見える）。保護者どうしは名前が見える。保護者どうしのあいさつスタンプは 👋🙇😊👍🌸 だけ。
- 保護者会：管理画面「📊 入室状況」で日にち・はじまり・おわりの時刻を入れる（例：19:00〜20:00）。その時間だけ、保護者は中学生と同じルールで教室・自習室・テストの教室へ（高校生自習室はなし・10分の制限なし）。生徒はその時間は入室できない（「今は保護者会です。20:00から入れます」）。入室中の生徒には5分前に知らせ、時刻になったら退室。おわりの時刻で保護者は退室。保護者会の日は、生徒の🔥・がんばりサンタの日数・高校生の週の回数がとぎれない。
- 今日来た保護者：「📊 入室状況」に、名前・お子さん・来た時刻・いま入室中かが出る（オーナーだけ）。保護者への入退室のお知らせはなし。
- 面談ブース（ロビーの左下）：オーナーが「📊 入室状況」で許可した保護者・生徒だけ入れる（その日だけ）。先生は担当する教室に「面談ブース」をチェック。通話・画面共有は教室2と同じしくみで、面談ブースでは生徒・保護者もマイクで話せる。許可された保護者はその日10分の制限なし。
- ロビーのソファは保護者の席（生徒はすわれない）。
- 「🏠 わが子」：今日・今週の自習時間と🔥。スタンプ（👍がんばったね など）を1日1回タップすると、子どもが次に入室したときに「🏠 おうちの人から：…」と1回だけ出て、ロビーの「母達の木」に花が1つ咲く。木には「今月○家族が挑戦中」も表示。保護者のクイズの結果は子どもには出さない。

### 🤝 友だち紹介・体験
- 生徒はメニューの「🤝 友だちを招待」から、自分のアバター入りの招待カードとリンクをLINEで送れる。保護者は「🏠 わが子」の「🌷 お友だちのご家族に紹介する」から。
- リンクを開いた友だちは、ニックネームと学年を入れるだけで体験できる（初期は3日間）。体験中は記録が残らず、学年の木にも数えない。ほかの生徒の名前は見えない（招待した子だけ見える）。名札は「体験：○○」。
- 入塾したら、管理画面で「🎓 入塾にする」→ ログインIDを決めると、アバターのまま生徒のアカウントになる。体験なしで入塾した生徒には「🤝 紹介者」で登録できる。
- 生徒の紹介：2人におそろいの「なかよしひよこ🐥」。入塾の日から7日間、2人とも🔥（学年の最低時間）を続けたら「ペア自習のきらきら星💫」と30ポイントずつ。
- 保護者の紹介：入塾したら母達の木に🌷が咲き、紹介した保護者に50ポイント。
- 🎉 友だち紹介ウィーク：管理画面「📊 入室状況」で期間を決めると、その間は体験の日数がのびて、生徒の画面にお知らせが出る。

### 季節のお楽しみ
- **🎅 がんばりサンタ**：11/1〜11/30に「学年ごとの1日の最低時間（中1 45分・中2 60分・中3 90分など。連続自習🔥と同じ）」以上自習した日が10日以上の生徒は、12/1〜12/7に入室するとプレゼント箱が届きます。開けると、お店では買えないクリスマスのアイテムが入っています。11月は画面の左上に「🎅 がんばりサンタ 7/10日」と出ます。
- **🌅 朝活チャレンジ**：朝6:00〜7:30（変更可）に30分以上自習した日に「早起きスタンプ」と3ポイント。
- オン/オフと条件は「🏆 がんばり」→「🎉 季節のお楽しみ」で変えられます。

### 誕生日のお祝い
- 管理画面の「ユーザー」で生徒を編集し、**誕生日（月・日だけ）** を登録します。「ほかの生徒にも誕生日を見せる」をはずすと、🎂は先生・オーナーと本人にだけ見えます。
- 誕生日にはじめて入室すると、**お祝いカード**が出て「🎂 バースデーケーキの帽子」（お店では買えないアイテム）をプレゼントします。カードのひとことは「🏆 がんばり」→「🎂 誕生日のお祝い」で変えられます。
- その日は**名札が金色になり🎂**がつき、その生徒の**学年の木にケーキ**が飾られます。
- 先生には入室のお知らせで「🎂 今日は誕生日です」と届きます（アプリを閉じているときはプッシュ通知）。
- 2/29生まれの生徒は、うるう年でない年は2/28に祝います。

### 吹き出し（先生・オーナーはどこでも／生徒は先生と話すときだけ）
- 下の **「💬 吹き出し」** ボタンで、アバターの上に短い文（24文字まで）を出せます。
  - 先生・オーナー：どの部屋でも使えます。「質問受付中」「面談中」などから選ぶか、自由に書きます。
  - 生徒：集中のさまたげにならないよう、**先生・オーナーに話しかけられたとき（近く3マスほどに来た・個別通話中）だけ**「💬 吹き出し」「😊 スタンプ」のボタンが出ます。先生がはなれるとボタンも吹き出しも消えます。**授業中の教室では、授業をしている先生が上のバーの「🤐 スタンプ・吹き出し止め中／😊 スタンプ・吹き出しOK」で許可したときだけ**使えます（授業を始めたときは止めています。止めると生徒の吹き出しは消えます）。
- 先生（生徒への個別対応の権限あり）は、アバターをタップ →「吹き出しを消す」で、ほかの人の吹き出しを消せます。
- 自習室の生徒の頭の上には、かわりに **今日の自習時間** が出ます（例「📚 今日 1時間20分」。10分までは1分ごと、1時間までは5分ごと、それより上は10分ごと）。
- 自習室では「手をあげる」は表示されません（挙手は授業の教室で使います）。

### 自習室の見守り写真（追加機能・無料）
- オーナーが管理画面「教室の設定」で**オン**にしたときだけ動きます（最初はオフ）。**保護者と生徒の同意を取ってからオンにしてください。**
- 自習室に入った生徒に案内が出て、生徒が自分で「カメラをオンにする」を押すと始まります。カメラの映像は動画ではなく**静止画**で、声・画面共有の LiveKit は使いません（無料枠を減らしません）。
- 写真は **7〜13分おきのランダムな時間**に撮られ、生徒には撮影の時間は表示されません。先生は **「📸 今すぐ撮る」** でいつでも撮れます（30秒に1回まで）。
- 先生の「📷 自習室」タブに、生徒ごとの最新の写真と、次の注意が出ます。
  - 💤 アプリを閉じています／別の画面を操作中
  - 📷 カメラオフ
  - ⚫ 真っ暗（カメラが隠れている？）
  - 🗿 30分以上ほとんど動きなし
  - ⏱ 写真が届いていません
- 見られるのはオーナーと「生徒への個別対応」の権限がある先生だけです。写真は**最新の1枚だけ**をサーバーのメモリに置き、データベースには保存しません。**自習室を出ると消えます。**
- 前と**まったく同じ写真ファイル**は受け付けません（保存しておいた写真の使い回し防止）。

### 第4段階のルール（個別通話）
- 呼び出せるのは**個別通話の権限がある先生**だけです。相手は、その先生の担当教室か自習室にいる生徒に限られます。**生徒からはだれも呼び出せません**（その機能自体がありません）。
- 呼び出し方：生徒のアバターをタップ →「🎧 個別通話をする」、または「挙手」一覧・「入室者」一覧のボタン。
- 生徒には参加確認（「参加する」「あとで」）が出ます。30秒応答がなければ自動で取り消されます。
- 参加すると、**ふたりは授業の通話から外れます**（サーバーが授業の部屋から退出させ、授業用のトークンも発行しません）。個別通話は毎回新しい別の部屋で行うので、ほかの生徒には聞こえず、授業の声も混ざりません。
- 授業中の先生が個別通話に入ると、教室の生徒には「先生はいま個別指導中です」と表示されます。
- 先生は画面共有（PCから）、生徒は「📷 ノートを見せる」（背面カメラ）が使えます。スマホのブラウザは画面共有ができないため、生徒にはカメラで代わりにしています。
- どちらかが「通話を終わる」を押すか、どちらかの接続が切れると終了します。終了すると授業の音声に自動で戻ります（先生のマイクは個別通話前の状態に戻ります。画面共有は、もう一度押して始め直してください）。
- 挙手していた生徒は、個別通話に参加すると挙手が自動で取り消されます。
- 録音・録画はしません。操作ログには「だれとだれが・いつ・何分」だけが残ります。

### 第3段階のルール（授業の通話）
- 「授業を始める」ボタンは、**通話の開始権限がある先生が担当教室の中にいるとき**だけ表示されます。1つの教室で同時に授業ができるのは1人です。
- 授業中の教室に入った人は自動で通話につながります。**生徒は聞く・見るだけ**です（マイクは使いません。発言は挙手で知らせます）。
- 画面共有はパソコンのブラウザからのみ使えます（スマホのブラウザは画面共有に対応していないため）。画面共有の権限がない先生のトークンには、画面共有の許可が入りません。
- 教室を出た人は、サーバーが通話から退出させます。ほかの教室・ろうか・自習室には声は届きません。
- 授業中の先生は教室から出られません（先に「授業を終わる」）。先生の通信が切れた場合は60秒待ち、戻らなければ授業を自動で終了します。
- 授業中に先生の通話・画面共有の権限を外すと、授業は終了します。オーナーは管理画面の「入室状況」から授業を終了させられます。
- 録音・録画は行いません（LiveKit の録画機能は使っていません）。

### 第2段階のルール
- 定員は**生徒の人数**です。先生・オーナーは数えません。
- 先生は担当の教室だけに入れます。オーナーはすべての教室に入れます。
- 挙手は**授業の教室の中にいる生徒**だけができます。教室を出ると自動で取り消されます。
- 挙手の通知は、その教室の担当で「生徒への個別対応」の権限がある先生と、オーナーに届きます。
- 管理画面で入室の権限を外すと、教室にいる人は自動でろうかへ移動します。
- 同じアカウントで別の端末から入ると、前の端末は切断されます。

## LiveKit Cloud の設定（音声・画面共有に必要）

1. https://cloud.livekit.io でアカウントを作り、プロジェクトを作成します。
2. プロジェクトの設定画面（Settings → API Keys）で API キーを作成し、次の3つを確認します。
   - **URL**（`wss://〜.livekit.cloud`）
   - **API Key**
   - **API Secret**（作成時に一度だけ表示されます）
3. `metaverse/.env.example` を `metaverse/.env` という名前でコピーし、3つの値を書き込みます（`.env` は Git には入りません）。本番のサーバー（Render など）では、同じ名前の「環境変数」として設定します。
4. `npm start` で起動し直します。

> **API Secret は誰にも見せないでください。** チャットやメールに貼らず、`.env` または公開先サービスの環境変数の設定画面にだけ入力してください。
> 設定していない場合、授業の通話ボタンには「通話サーバー（LiveKit）が未設定」と表示され、そのほかの機能はそのまま使えます。

## 起動方法

Node.js 22.13 以上が必要です（データベースは Node.js 標準の SQLite を使うので、追加インストールは不要です）。

```bash
cd metaverse
npm install
npm start
# → http://localhost:3000
```

データは `metaverse/data/app.db` に保存されます（`DB_PATH` で変更可）。

| 環境変数 | 説明 |
| --- | --- |
| `PORT` | ポート番号（既定 3000） |
| `DB_PATH` | データベースファイルの場所 |
| `NODE_ENV=production` | Cookie を HTTPS 専用にする（本番では必ず設定） |
| `TRUST_PROXY=1` | Render などのプロキシの後ろで動かすとき |
| `SESSION_DAYS` | ログインの有効日数（既定 7） |
| `LIVEKIT_URL` / `LIVEKIT_API_KEY` / `LIVEKIT_API_SECRET` | LiveKit Cloud の接続情報（上記） |
| `CLASS_GRACE_MS` | 先生の通信が切れてから授業を自動終了するまでの時間（既定 60000 ミリ秒） |
| `DATABASE_URL` | データの保存先（Neon などの PostgreSQL）。設定すると、データを数秒ごとに自動保存し、起動時に読み戻します。無料のサーバー（再起動でファイルが消える）でもデータが消えません。つながらないときはデータの上書きを防ぐため起動を止めます |
| `AUDIT_RETENTION_DAYS` | 操作ログ（IPアドレスを含む）の保存日数。過ぎたものは自動削除（既定 180） |

`.env` ファイルがあれば `npm start` で自動的に読み込みます。

### 第3段階の確認手順（LiveKit Cloud の設定後）
いちばん確実なのは、**同じパソコンでブラウザを2つ**使う方法です（`http://localhost` ならマイク・画面共有が使えます）。
1. ブラウザA（通常）：先生でログイン →「へや」→ 担当の教室 → 教壇へ。上に出る「📢 授業を始める」を押す → マイクの許可を「許可」。
2. ブラウザB（シークレット）：生徒でログイン → 同じ教室へ。上に「🎙 授業中」と「🔊 タップして音声をきく」が出るので押す → 先生の声が聞こえることを確認（ハウリングを防ぐため、片方はイヤホンで）。
3. 先生が「🖥 画面共有」→ 共有する画面を選ぶ → 生徒側に先生の画面が出る。「⛶ 大きく」で全画面表示。
4. 生徒が教室から出る → 声と画面が止まる。別の教室・自習室では聞こえない。
5. 先生が「授業を終わる」→ 生徒側の表示が消える。

スマホで確認するときは、アプリを **HTTPS で公開**してから行ってください（スマホのブラウザは、HTTPS でないページでは通話機能を制限することがあります）。iPhone では最初に「タップして音声をきく」を押す必要があります。

### 第4段階の確認手順（LiveKit Cloud の設定後）
ブラウザを3つ（先生・生徒A・生徒B）使います。
1. 先生が担当教室で「授業を始める」。生徒A・Bも同じ教室で「タップして音声をきく」→ 先生の声が聞こえる。
2. 生徒Aが「手をあげる」→ 先生の「挙手」一覧で「🎧 個別通話」を押す。
3. 生徒Aに「参加する／あとで」が出る →「参加する」→ 先生と生徒Aが話せる。**生徒Bには2人の声が聞こえず**、「先生はいま個別指導中です」と出る。
4. 先生が「🖥 画面共有」→ 生徒Aにだけ先生の画面が出る。生徒Aがスマホなら「📷 ノートを見せる」→ 先生に背面カメラの映像が出る。
5. 生徒Aが「通話を終わる（授業にもどる）」→ 2人とも授業の音声に戻り、生徒Bにも先生の声がまた聞こえる。

### 手で確認する手順（第2段階）
ブラウザを3つ（通常＋シークレット、または別のブラウザ・スマホ）用意します。
1. オーナーでログイン → 管理画面で先生（担当：教室1）と生徒2人を作る → 「教室の設定」で教室1の定員を **1人** にする。
2. 先生でログイン → 「へや」→ 教室1 → 教壇へ移動。
3. 生徒Aでログイン → 「へや」→ 教室1 → 席に座る。先生の画面に生徒Aのアバターが動いて見える。
4. 生徒Bでログイン → 「へや」を開くと教室1が「満員」。歩いて入ろうとしても入口で止められる。
5. 生徒Aが「手をあげる」→ 先生の画面に通知・チャイム・「挙手」ボタンに数字。「挙手」一覧の「対応済み」で生徒Aの手がおりる。
6. 生徒が「スタンプ」を押すと、アバターの上に絵文字が出る（全員に見える）。
7. オーナーの管理画面「入室状況」で人数と名前が見える → 生徒Bを「切断してログアウト」→ 生徒Bの画面はログイン画面に戻る。

## セキュリティ（実装済みのもの）
- パスワードは scrypt でハッシュ化して保存。ログイン試行は同じIDで5回失敗すると15分ロック。
- ログイン状態はサーバー側セッション（HttpOnly・SameSite Cookie）。無効化・パスワード再発行・強制ログアウトで即座に無効化。
- 管理APIはすべてサーバー側で役割・権限を確認。生徒には通話・画面共有・管理の権限を付けられない（APIで送っても保存されない）。
- 他サイトからの書き込みリクエスト・WebSocket 接続を拒否、Content-Security-Policy などのセキュリティヘッダーを設定。
- リアルタイム接続もログイン Cookie で認証。位置・入室・着席・挙手はサーバーが判定し、画面側の判定をすり抜けても入室できない。
- ログインが無効になった接続は30秒以内に自動で切断（強制ログアウト・無効化は即時）。
- 通話の参加トークンはサーバーだけが発行（有効期限10分・その教室だけ・生徒は送信不可・録画権限なし）。API Secret はブラウザに渡さない。
- 個別通話は先生からのみ開始でき、生徒の参加確認が必要。個別通話の部屋のトークンは当事者2人にしか発行されない。
- LiveKit のライブラリは外部サイトからではなく、このサーバーから配信。
- 連打対策：リアルタイム通信は1人あたり平均10回/秒まで、挙手は3秒に1回まで。パスワード変更も5回失敗でロック。
- 操作ログは180日で自動削除。
- **サーバーは1台で運用してください**（入室状況をサーバーのメモリで管理しているため）。
- 個人情報は表示名・ログインID・役割・色のみ保存。
- 本番は HTTPS（`NODE_ENV=production`）で運用してください。
