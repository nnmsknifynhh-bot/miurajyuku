# はじめかた（公開して、スマホで試すまで）

むずかしい操作はありません。**3つのステップ**を順番に進めてください。
画面は英語ですが、押す場所を書いています。画面がこの説明と違うときや、途中でわからなくなったときは、その画面の様子を教えてください。

---

## ステップ1　LiveKit Cloud（音声・画面共有のサービス）に登録する　約5分・無料

1. パソコンで https://cloud.livekit.io を開きます。
2. **「Sign up」**（または「Continue with Google」）を押して、Google アカウントなどで登録します。
3. プロジェクトの名前を聞かれたら、`miurajuku` などと入力して作成します。
4. 左のメニューから **「Settings」→「API Keys」**（または「Keys」）を開きます。
5. 次の **3つ** を、メモ帳などにコピーしておきます。
   - **URL**：`wss://〜.livekit.cloud` のような文字
   - **API Key**：`API` で始まる文字
   - **API Secret**：長い文字。「Reveal」や目のマークを押すと表示されます

> ⚠️ **API Secret は「合いかぎ」のようなものです。** チャット・メール・LINE には貼らないでください。ステップ2の画面にだけ貼り付けます。

---

## ステップ2　Render（アプリを動かすサービス）で公開する　約10分・月7ドル程度

1. https://render.com を開き、**「Get Started」→「GitHub」** を選んで、いつもの GitHub アカウントで登録します。クレジットカードの登録を求められたら登録します。
2. 画面上の **「New +」→「Blueprint」** を押します。
3. GitHub との連携を求められたら許可して、リポジトリ **「miurajyuku」** を選びます。
4. ブランチ（Branch）を選ぶ欄があれば、**`claude/2d-virtual-tutoring-app-q85m52`** を選びます。
5. 入力欄が3つ出てきます。ステップ1でコピーした値を貼り付けます。
   - `LIVEKIT_URL` ← URL
   - `LIVEKIT_API_KEY` ← API Key
   - `LIVEKIT_API_SECRET` ← API Secret
6. **「Apply」**（または「Deploy Blueprint」）を押します。数分待ちます。
7. 画面に **「Live」** と出たら完成です。`https://miurajuku-online.onrender.com` のようなアドレスが表示されるので、それが**アプリのアドレス**です。

> 料金について：無料プランもありますが、無料プランはデータ（アカウントなど）を保存できず、再起動のたびに消えてしまうため、月7ドル程度の「Starter」プランになっています。

## ステップ3　動作を確かめる　約10分

### 3-1. はじめての設定（パソコン）
1. ステップ2のアドレスをパソコンで開きます。
2. 「はじめての設定」画面で、**塾長（オーナー）のアカウント**を作ります（表示名・ログインID・パスワード）。
3. 管理画面が開いたら **「＋ユーザーを追加」** →「生徒」を選び、テスト用の生徒を1人作ります。
   作成後に出るログイン情報をメモします。

### 3-2. 声が届くか試す（パソコン＝先生役、スマホ＝生徒役）
1. **パソコン**：左上の「← 教室へもどる」→ 下の「へや」→「教室1」→ 教壇まで歩きます。
   画面上に出る **「📢 授業を始める」** を押し、マイクの使用を **「許可」** します。
2. **スマホ**：同じアドレスを開き、3-1で作った生徒でログインします → 「へや」→「教室1」→ 席に座ります。
   **「🔊 タップして音声をきく」** を押します。
3. パソコンに向かって話します → **スマホから声が聞こえれば成功**です。
   （ハウリングを防ぐため、スマホはイヤホンで聞くか、少し離してください）
4. 余裕があれば、パソコンで **「🖥 画面共有」** を押して、スマホに画面が映るかも見てください。

### 3-3. 結果を教えてください
- 「声が聞こえた」「聞こえなかった」
- 画面に出たメッセージ（例：「通話サーバーにつながりません」）

これを教えてもらえれば、うまくいかなかった場合も原因を探して直します。

### スマホのホーム画面に追加する（アプリのように使う）
- **iPhone**：Safari でアドレスを開く → 下の共有ボタン（□に↑）→「ホーム画面に追加」
- **Android**：Chrome でアドレスを開く → 右上の「︙」→「ホーム画面に追加」（または「アプリをインストール」）
