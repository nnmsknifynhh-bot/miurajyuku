# はじめかた（無料で公開して、スマホで試すまで）

**4つのステップ**を順番に進めます。すべて**無料**です（クレジットカードの登録も基本的に不要です）。
画面は英語ですが、押す場所を書いています。画面がこの説明と違うときや、わからなくなったときは、見えている画面の文字を教えてください。

| ステップ | サービス | 役割 | 時間 |
| --- | --- | --- | --- |
| 1 | LiveKit Cloud | 声・画面共有をつなぐ | 約5分 |
| 2 | Neon | データ（アカウント・設定）を保存する | 約5分 |
| 3 | Render | アプリをインターネットで動かす | 約10分 |
| 4 | ― | スマホで試す | 約10分 |

> ⚠️ ステップ1・2でコピーする「API Secret」と「接続文字列」は、**合いかぎ**のようなものです。
> チャット・メール・LINE には貼らず、ステップ3の Render の画面にだけ貼り付けてください。

---

## ステップ1　LiveKit Cloud（声・画面共有）　無料：月5,000分まで

1. パソコンで https://cloud.livekit.io を開き、**「Sign up」**（または「Continue with Google」）で登録します。
2. プロジェクトの名前を聞かれたら `miurajuku` と入力して作成します。
3. 左のメニューの **「Settings」→「API Keys」**（または「Keys」）を開きます。
4. 次の3つをメモ帳にコピーします。
   - **URL**（`wss://〜.livekit.cloud`）
   - **API Key**（`API` で始まる文字）
   - **API Secret**（「Reveal」や目のマークを押すと表示される、長い文字）

## ステップ2　Neon（データの保存）　無料：1GBまで

1. https://neon.com を開き、**「Sign up」**（Google や GitHub のアカウントで登録できます）。
2. プロジェクトを作ります。
   - 名前：`miurajuku`
   - 地域（Region）：**「AWS Asia Pacific (Singapore)」**など、アジアのものを選びます
3. 作成後の画面にある **「Connect」**（または「Connection string」）を押し、`postgresql://` で始まる長い文字をコピーします。これが**接続文字列**です。

## ステップ3　Render（アプリを動かす）　無料プラン

1. https://render.com を開き、**「Get Started」→「GitHub」** で、いつもの GitHub アカウントで登録します。
2. 画面上の **「New +」→「Blueprint」** を押します。
3. GitHub との連携を許可して、リポジトリ **「miurajyuku」** を選びます。
   ブランチ（Branch）を選ぶ欄があれば、**`claude/2d-virtual-tutoring-app-q85m52`** を選びます。
4. 入力欄が4つ出てきます。ステップ1・2でコピーしたものを貼り付けます。
   - `DATABASE_URL` ← Neon の接続文字列（postgresql://〜）
   - `LIVEKIT_URL` ← LiveKit の URL（wss://〜）
   - `LIVEKIT_API_KEY` ← LiveKit の API Key
   - `LIVEKIT_API_SECRET` ← LiveKit の API Secret
5. **「Apply」**（または「Deploy Blueprint」）を押し、数分待ちます。
6. **「Live」** と出たら完成です。`https://miurajuku-online.onrender.com` のような**アプリのアドレス**が表示されます。

## ステップ4　スマホで試す（個別通話）

### 4-1. はじめての設定（パソコン）
1. アプリのアドレスをパソコンで開きます。
2. 「はじめての設定」で、**塾長（オーナー）のアカウント**を作ります。
3. 管理画面の **「＋ユーザーを追加」→「生徒」** で、テスト用の生徒を1人作ります（ログイン情報をメモ）。

### 4-2. 個別通話を試す（パソコン＝先生役、スマホ＝生徒役）
1. **スマホ**：同じアドレスを開き、テスト用の生徒でログイン →「へや」→「教室1」→ 席に座ります。
2. **パソコン**：「← 教室へもどる」→「へや」→「教室1」へ。
   画面の中の生徒のアバターをクリック → **「🎧 個別通話をする」** を押します。
3. **スマホ**：「先生から、個別通話のおさそいです」と出るので **「参加する」** → マイクを「許可」。
4. おたがいに話してみて、**声が聞こえれば成功**です（ハウリングを防ぐため、片方はイヤホンで）。
5. できれば、パソコンで **「🖥 画面共有」**、スマホで **「📷 ノートを見せる」** も試します。
6. **「通話を終わる」** を押して終了します。

### 4-3. データが消えないかの確認
- 次の日などにもう一度アドレスを開いて、作ったアカウントでログインできれば、データは正しく保存されています。
  （無料プランは、15分使わないとアプリが眠ります。開いたときに1分ほど待たされることがありますが、故障ではありません）

### 4-4. 結果を教えてください
- 「声が聞こえた／聞こえなかった」
- 画面に出たメッセージ（例：「通話サーバーにつながりません」）

## 無料で使うときの目安
- **声・画面共有**：月5,000分（人数×分）まで。例：2人の個別通話を2分 × 週3日 × 5人 ＝ 月 約260分。
  超えても料金はかからず、その月は通話がつながらなくなるだけです。
- **アプリの通信量**：月5GBまで。生徒15人が毎日1時間くらいなら収まる見込みです。
- **授業（全体通話）を使ったら、必ず「授業を終わる」**を押してください。教室にいる人数分の分数が数えられます。

## スマホのホーム画面に追加する（アプリのように使う）
- **iPhone**：Safari でアドレスを開く → 下の共有ボタン（□に↑）→「ホーム画面に追加」
- **Android**：Chrome でアドレスを開く → 右上の「︙」→「ホーム画面に追加」
