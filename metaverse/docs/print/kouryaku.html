STAGE 1

🚪 はじめての冒険

入ってから、すわるまで

1ログイン

塾からもらったIDとパスワードで入るよ。アプリを入れなくても、スマホ・タブレット・パソコンのブラウザでOK。

2漢字テスト（4択）

入る前に、漢検の読みが1問出るよ。正解でもまちがえても、正しい読みを見てから入れる。

3「🏫 へや」で自習室へ

中学生は「自習室」、高校生は「高校生自習室（カフェ）」へ。歩いて行ってもいいよ。

4席にすわって、勉強スタート！

いすをタップするか「すわる」。すわると自習時間を数えはじめるよ。

自習室のようす。頭の上の「📚 今日○分」が、今日の自習時間
攻略のコツ　自分のアバターの頭の上に「📚 今日 1時間10分」と出るよ。友だちのがんばりも見えるから、いっしょにがんばろう！

MAP

🗺 塾の地図・部屋ガイド

どこに何があるかな？

🏠 ロビー（入口）

最初に来る場所。先生の黒板、保護者のソファ、家族の木、面談ブース（許可された人だけ）があるよ。ソファは保護者の席なので、生徒はすわれない。

📚 自習室（中学生）

仕切りつきの32ブース。真ん中に中1・中2・中3の木。ここで勉強すると時間を数えるよ。しずかに集中する部屋。

☕ 高校生自習室（カフェ）

高校生だけの、カフェ風の部屋。「今日やること」を3つ書いてスタート。高校生の木もあるよ。

🎤 テスト教室

スピーキング・ライティングのテスト。前にブースが2つ。うしろの席で自習しながら順番を待つ。

🏫 教室2

授業の教室。先生の声と画面共有が届くよ。生徒は聞くだけ、質問は✋挙手で。

🚶 ろうか

部屋と部屋をつなぐ道。季節の飾りが出るよ。「🏫 へや」で一気に移動もできる。

💪 つよくなる方法 その1

🔥連続自習・ポイント・着せかえ

🔥 連続自習

毎日、学年の最低時間をこえて自習すると🔥がふえる！ 名前の横に出るよ。

学年1日の最低時間
中145分
中260分
中390分
高校生週で数える（3時間以上の日が週2回）

授業の曜日は、自習できなくても🔥がとぎれないよ。保護者会の日も大丈夫。

📚 今日の時間

自習室で勉強した時間は、ぜんぶ「今日○分」として頭の上に出るよ。夜おそくても、土日でも数える。

🎁 ポイントと着せかえ

自習10分で1ポイント。帽子・洋服・眼鏡・杖や剣・ペット・着ぐるみと交換できる！ 学年が変わってもポイントとアイテムはそのまま。お店では買えない、季節のクエストや誕生日だけの特別アイテムもあるよ。

攻略のコツ　ポイントがたまったら「メニュー → 🎁 ポイントと着せかえ」。着せかえ期間（冬休みなど）に着られるよ。

STAGE 2

💪 つよくなる方法 その2

学年の木・目標の短冊・マイ席

🌳 学年の木（みんなで育てる）

自習室の真ん中に、中1・中2・中3の木（高校生自習室には高校生の木）。学年の1人あたりの平均自習時間で、芽 → 若葉 → 若木 → 大きな木 → 花 → 実りと育つよ。競争じゃなくて協力。木をタップすると、くわしく見られる。

🎋 目標の短冊

メニュー「🎯 今学期の目標」に目標を書くと、先生が確認してから、自分の学年の木に短冊としてかざられるよ。目標を達成すると、短冊が⭐に変わる！

木にかざられた短冊。⭐は目標を達成した印
木をタップ → みんなの目標が読める

⭐ マイ席（自分だけの指定席）

🔥が30日（高校生は4週）続くと、好きな席を「マイ席」にできる！ 金色の名前プレートがついて、すわると光るよ。入ると自動でマイ席へ案内。🔥がとぎれたら返すから、続けよう。

攻略のコツ　🔥が10日をこえると、画面の左上に「⭐ マイ席まで 🔥22/30日」と出るよ。

RULE

🧭 自習室のルール

みんなが集中できるように

📷 見守りカメラ

自習室に入ると「カメラをオンにする」が出るよ。スマホを、自分とノートが写る場所に置いてね。ときどき写真が撮られて、先生にだけ届く（いつ撮るかはひみつ）。写真は自習室を出ると消えるよ。

🪑 席にすわろう

自習室で10秒以上立ち歩くと「立ち歩きが10秒をこえたよ。席にすわって勉強しよう！」と出て、空いている席がえらべるよ。「近くの席にすわる」でもOK。

  • 💬 吹き出し・スタンプは、先生が近くに来て話しかけたときだけ使える。
  • 📱 アプリを閉じたり、ほかの画面を見たりすると、時間が止まる。
  • 🔌 通信が切れても、すぐもどれば元の席に。

🌙 省電力画面

すわって1分さわらないと、黒い画面になって電池を節約。時間はそのまま数えるよ。長い自習は充電しながらね。

GUIDE

👩‍🏫 先生とオーナー

こまったら、先生をさがそう

先生とオーナーは、みんなより1.4倍大きくて、スーツ姿。すぐに見つけられるよ

👔 見分け方

先生はオレンジのネクタイ、オーナーはむらさきのネクタイ。名札にも「先生」「オーナー」と出るよ。

🙋 質問したいとき

先生が近くに来ると、💬吹き出しと😊スタンプが使えるようになるよ。授業の教室では✋挙手で知らせよう。

🎧 個別通話

先生から「個別通話」の呼び出しが来たら「参加する」。ふたりだけで話せるよ。ノートはカメラで見せられる。

👀 いつも見守り

先生・オーナーは塾全体を見わたせる。がんばっている姿は、ちゃんと見ているよ。

ロビーの黒板には、先生からのメッセージ。新しくなるとお知らせが出るよ

FAMILY

🏠 おうちの人へ

保護者の方も参加できます

  • 塾からお渡しする招待コードで登録できます。
  • 入れるのはロビーだけ（1日1回・10分）。ソファにすわると塾全体を見わたせます。
  • 「🏠 わが子」で、今日・今週の自習時間と🔥、📅 勉強の足あとカレンダーが見られます。
  • 「見たよ」スタンプを1タップ → 子どもが次に入ったとき「🏠 おうちの人から」と届き、ロビーの家族の木に花が咲きます。
  • 毎日5問のクイズでポイントもたまります。
  • 保護者の名前は子どもには表示されません。ほかの子の名前も保護者には表示されません。
  • 保護者会の日は、全部の教室を子どもと同じルールで体験できます。
