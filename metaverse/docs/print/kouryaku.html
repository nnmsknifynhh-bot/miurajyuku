STAGE 1

🚪 はじめての冒険

入ってから、すわるまで

1ログイン

塾からもらったIDとパスワードで入るよ。アプリを入れなくても、スマホ・タブレット・パソコンのブラウザでOK。

2漢字テスト（4択）

入る前に、漢検の読みが1問出るよ。正解でもまちがえても、正しい読みを見てから入れる。

3「🏫 へや」で自習室へ

中学生は「自習室」、高校生は「高校生自習室（カフェ）」へ。歩いて行ってもいいよ。

4席にすわって、勉強スタート！

いすをタップするか「すわる」。すわると自習時間を数えはじめるよ。

自習室のようす。頭の上の「📚 今日○分」が、今日の自習時間
攻略のコツ　自分のアバターの頭の上に「📚 今日 1時間10分」と出るよ。友だちのがんばりも見えるから、いっしょにがんばろう！

STAGE 2

💪 つよくなる方法

🔥・ポイント・着せかえ・木・マイ席

🔥 連続自習

毎日、学年の最低時間をこえて自習すると🔥がふえる！

学年1日の最低時間
中145分
中260分
中390分
高校生週で数える（週のノルマ）

授業の曜日は、自習できなくても🔥がとぎれないよ。

🎁 ポイントと着せかえ

自習10分で1ポイント。帽子・洋服・ペット・着ぐるみと交換できる！ 学年が変わってもポイントはそのまま。

🌳 学年の木

学年みんなの自習時間で、芽 → 花 → 実 と育つよ。目標の短冊もかざれる。みんなで協力！

⭐ マイ席（自分だけの指定席）

🔥が30日（高校生は4週）続くと、好きな席を「マイ席」にできる！ 金色の名前プレートがついて、すわると光るよ。🔥がとぎれたら返すから、続けよう。

攻略のコツ　ポイントがたまったら「メニュー → 🎁 ポイントと着せかえ」。🔥が10日をこえると、画面の左上に「⭐ マイ席まで 🔥22/30日」と出るよ。

🎤 テスト教室

スピーキング・ライティングのテストは順番待ち。呼ばれたらブースへ。待っている間も自習時間になるよ。

🪟 窓の景色

窓の外は、朝焼け・青空・夕焼け・星空に変わる。春は桜、夏は入道雲、秋は紅葉、冬は雪。

🤝 友だちを招待

メニュー「🤝 友だちを招待」でLINEに招待カード。友だちが入塾したら、2人におそろいの🐥！ 7日間2人とも🔥で、きらきら星💫と30ポイント。

RULE

🧭 自習室のルール

みんなが集中できるように

  • 💬 吹き出し・スタンプは、先生と話すときだけ。授業中は先生がOKを出したときだけ。
  • 🚶 自習室で10秒以上立っていると、席にすわるように声がかかるよ。
  • 📱 アプリを閉じたり、ほかの画面を見たりすると、時間が止まる。
  • 🔌 通信が切れても、すぐもどれば元の席に。切れていた分も数えるよ。
  • 🌙 長い時間の自習は、充電しながら。1分さわらないと、黒い省電力画面になるよ（時間はそのまま）。

🏠 おうちの人へ

保護者の方も参加できます

  • 塾からお渡しする招待コードで登録できます。
  • 入れるのはロビーだけ（1日1回・10分）。ソファにすわると塾全体を見わたせます。
  • 「🏠 わが子」で、今日・今週の自習時間と🔥、📅 勉強の足あとカレンダーが見られます。
  • 「見たよ」スタンプを1タップ → 子どもが次に入ったとき「🏠 おうちの人から」と届き、ロビーの家族の木に花が咲きます。
  • 保護者の名前は子どもには表示されません。ほかの子の名前も保護者には表示されません。
