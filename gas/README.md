# 宿題 自動採点の設定手順（無料）

生徒が問題集の写真を送る → Googleドライブの解答と照らし合わせてAIが ○× をつける →
先生の「採点」タブに届く → 先生が「返却」を押す → 生徒の「宿題」タブに結果が返る、という仕組みです。

使うもの（どれも無料）:

| 役割 | サービス |
|---|---|
| 写真・解答・記録の保存 | Google ドライブ／スプレッドシート |
| 生徒と先生のあいだの受け渡し | Google Apps Script |
| 採点（写真の読み取りと照合） | Gemini API の無料枠（Googleアカウントだけで使えます。クレジットカード不要） |

所要時間：20分ほど。最初に一度だけ行います。

---

## 1. Gemini の APIキーを取る（3分）

1. パソコンで https://aistudio.google.com/apikey を開き、塾のGoogleアカウントでログイン
2. 「APIキーを作成」を押す
3. 表示されたキー（`AIza…` で始まる長い文字列）をコピーしてメモ帳などに貼っておく

> 無料枠では、1日に数百回ほど採点できます（Googleの設定により変わることがあります）。
> 上限を超えると、その日は「採点エラー」になります。翌日に先生の画面から「AIで採点し直す」を押せば採点されます。

## 2. Apps Script を作る（5分）

1. https://script.google.com を開き、「新しいプロジェクト」を押す
2. 左上の「無題のプロジェクト」を押して、名前を「三浦塾 採点」に変える
3. 最初から入っている `function myFunction() {…}` をすべて消す
4. このフォルダの **`Code.gs` の中身を全部コピー**して貼り付ける
5. 一番上の「★ 設定」のところを書き換える

   ```js
   GEMINI_API_KEY: 'AIza…（1でコピーしたキー）',
   APP_TOKEN: 'miura-juku-2026',          // 生徒用の合言葉（このままでもOK）
   ADMIN_TOKEN: 'ここに先生だけが知る合言葉', // ← 必ず変える（例: miura-sensei-0815）
   ```

6. 💾（保存）を押す

## 3. 初期設定を実行する（3分）

1. 上部の関数の選択欄で **`setup`** を選び、「▶ 実行」を押す
2. 「承認が必要です」と出たら、次の順に進む
   - 「権限を確認」→ 自分のアカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たら「詳細」→「三浦塾 採点（安全ではないページ）に移動」→「許可」
     （自分で作ったプログラムなので問題ありません）
3. 下の実行ログに「準備完了！」と出れば成功
   → マイドライブに **`三浦塾_採点`** フォルダができています
4. 関数の選択欄で **`testGemini`** を選んで実行し、ログに「準備OK」と出ればAIの設定も完了です

## 4. ウェブアプリとして公開する（3分）

1. 右上の「デプロイ」→「新しいデプロイ」
2. 歯車アイコン →「ウェブアプリ」を選ぶ
3. 次のように設定する
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」を押し、表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー

> 「全員」にしても、合言葉を知らない人は何もできません。写真や記録は先生のドライブにだけ保存されます。

## 5. アプリに URL を設定する（2分）

Netlify にアップロードしているフォルダ（`build/web`）の中の **`grading_config.json`** を開いて、URLを貼り付けます。

```json
{
  "gasUrl": "https://script.google.com/macros/s/xxxxxxxx/exec",
  "appToken": "miura-juku-2026"
}
```

- `appToken` は、2 の `APP_TOKEN` と同じにしてください
- このファイルを書き換えるだけで反映されます。アプリを作り直す必要はありません
- 保存したら、いつもどおり Netlify にアップロードしてください

## 6. 解答を入れる

ドライブの `三浦塾_採点/解答/` の中に、**問題集ごとにフォルダ**を作り、解答ページの写真やPDFを入れます。

```
三浦塾_採点/
├─ 解答/
│   ├─ 新研究 数学2年/        ← フォルダ名が、アプリで生徒が選ぶ「問題集名」になります
│   │   ├─ p12-13.jpg         ← ファイル名にページ番号を入れる
│   │   ├─ p14-15.jpg
│   │   └─ p40.pdf
│   └─ ワーク 英語1年/
│       └─ …
├─ 提出写真/                   ← 生徒の写真が自動で保存されます（生徒ごとのフォルダ）
└─ 提出一覧（スプレッドシート）   ← 提出・点数・返却の記録
```

- **ファイル名にページ番号を入れておく**と、生徒が入力したページの解答だけを使うので、採点が速く正確になります
  （例：生徒が「12」と入力 → `p12-13.jpg` だけを使う）
- 写真（JPG・PNG）、PDF、Googleドキュメント、Googleスプレッドシートに対応しています
- 最初からある「サンプル問題集」フォルダは、不要なら消してかまいません

## 使い方

**生徒**：「宿題」タブで 教科 → 問題集 → ページ を選び、1ページずつ撮影（1回 **4ページまで**）→「提出する」
（1分ほどでAIの採点と最終チェックが終わり、先生に届きます。生徒にはまだ結果は見えません）

**先生**：「採点」タブを開く（初回だけ `ADMIN_TOKEN` の合言葉を入力）
- 答案の写真に、問題集に書き込むのと同じように赤ペンで **○ / ×** が入り、×の横には **正しい答え**、右上に点数が書かれて届きます
- AIが確信を持てない問題は、オレンジの **「?」（保留）** になっています
- 写真の下には **×と保留だけ** が、ページ・問題番号の順に並びます（判定・生徒の解答・模範解答・原因・確認事項）
- 写真の印や一覧の判定をタップすると **○ → × → 保留** の順に変わります。点数も自動で変わります
- **保留が残っている間は返却できません**（最終判断は講師）。すべて判定したら **「返却する」**
- 右上のメニューから：
  - **保護者LINE報告を作成**：LINE報告ルールで文章を作成 →「コピー」でLINEに貼り付け
  - **この生徒の苦手分析**：その生徒の過去の採点記録だけから、繰り返す間違いと次回の演習を提案
  - **AIで採点し直す**

**生徒**：「宿題」タブに **NEW** が付き、先生が確認した赤ペン入りの答案写真（タップで拡大）と、
間違えた問題（模範解答・原因・復習）、先生のコメントが見られます

## 三浦塾の採点ルール（Code.gs に組み込み済み）

- 判定は **○・×・保留**。推測による採点は禁止。確信が持てない問題は必ず保留にし、理由と確認箇所を記録
- 模範解答と、数字・符号・単位・記号まで照合。x・y など複数の解答欄は別々に照合。正しい別解は○
- 数学は途中式も確認。原因は 計算ミス／符号ミス／立式ミス／理解不足／読み間違い・写し間違い／未解答 で記録
- 未解答（×）と判読困難（保留）を区別
- 正答率は保留を除いて計算し、保留件数は別に表示
- 1回目の採点のあと、**全小問をもう一度照合する最終チェック**を自動で行う（`VERIFY_PASS`）
- AIの答えをそのまま信じないよう、サーバー側でも次の場合は**必ず保留**にする
  - 模範解答の該当箇所を確認できなかった
  - 生徒の文字が読み取れない
  - 生徒の解答が模範解答と同じなのに×になっている
- 生徒ごとに記録を分け、別の生徒の答案や結果を混同しない（記録はスプレッドシートに生徒ID・学年・氏名つきで保存）

ルールの文章は `Code.gs` の `GRADING_RULES`（採点）と `LINE_RULES`（保護者報告）にあります。
言い回しを変えたいときは、そこを書き換えてください。

## Code.gs を書き換えたとき（アプリを更新したときも）

新しい `Code.gs` の中身を Apps Script に貼り直します。そのとき、★設定の部分（APIキー・合言葉）は元の値に戻してください。

「デプロイ」→「デプロイを管理」→ ✏️（編集）→ バージョン「新バージョン」→「デプロイ」。
URLは変わりません。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 生徒の画面で「採点サーバーが未設定です」 | 手順5の `grading_config.json` を確認 |
| 「合言葉が違います」 | `grading_config.json` の `appToken` と Code.gs の `APP_TOKEN` をそろえる |
| 先生の画面で「採点エラー」 | エラーの内容を確認 →「AIで採点し直す」。`429` は無料枠の上限なので、少し時間をおく |
| 「解答フォルダが見つかりません」 | フォルダ名が問題集名と一致しているか確認 |
| 問題集が選択肢に出ない | `解答` フォルダの**直下**にフォルダを作っているか確認 |

## 注意

- 正確性を優先して、1回の提出でAIを2回使います（採点＋最終チェック）。無料枠の上限に近づいたら、
  `VERIFY_PASS: false` にすると1回になります（正確性は下がります）。
- Gemini の**無料枠**では、送った内容（答案と解答の写真）がGoogleのサービス改善に使われることがあります。
  AIに送るのは写真と問題集名・ページだけで、生徒の名前は送りません。
  気になる場合は、Google AI Studio で課金を有効にすると、送った内容が改善に使われなくなります（その場合は有料です）。
- AIの採点は完璧ではありません。手書きの読み間違いがあるので、返却前にざっと確認することをおすすめします。
- 赤ペンの位置もAIが判断するので、少しずれることがあります。答えがはっきり写るよう、真上からまっすぐ撮るのがコツです。
